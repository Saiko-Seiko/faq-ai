# 運用マニュアル（人事ご担当者向け）

この文書は、システムを**日々お使いになる方**のためのものです。
技術的な設定は [05-deploy.md](05-deploy.md)、
なぜこの作りなのかは [06-production-plan.md](06-production-plan.md) をご覧ください。

## 画面の一覧

| 画面 | どなたが使うか | 何をするか |
|---|---|---|
| 会社説明会 `/briefing` | **応募者・求職者** | 動画を見て、チャットで質問する |
| AI面接 `/interview?token=…` | **応募者（招待された方のみ）** | 設問に回答する |
| 個人情報の取り扱い `/privacy` | **応募者** | 取り扱いの確認と、削除のご請求 |
| 選考状況 `/dashboard` | 閲覧のみ・選考担当・管理者 | 回答を読み、合否を決める |
| 候補者管理 `/candidates` | 選考担当・管理者 | 面接URLの発行と管理 |
| 運用の振り返り `/insights` | 選考担当・管理者 | AI評価のズレ、質問の抜けを見る |
| コンテンツ編集 `/content` | **管理者のみ** | チャットの回答・設問・会社情報の書き換え |
| 担当者管理 `/team` | **管理者のみ** | 担当者の追加・権限・操作ログ |

**応募者にお伝えするのは、上3つのURLだけです。**
それ以外の画面は、ログインしていなければ開けません。

## 権限

| 権限 | できること |
|---|---|
| 閲覧のみ | 記録と候補者を読む |
| 選考担当 | ＋ 合否とメモの記録、候補者の登録・招待 |
| 管理者 | ＋ 担当者の管理、コンテンツ編集、記録の完全削除 |

迷われたら**閲覧のみ**で発行してください。あとから上げられます。
合否を押していただく方だけ「選考担当」にする、という運用が安全です。

## ログイン

1. `/dashboard` を開くとログイン画面が出ます
2. ご自身の**メールアドレス**と、管理者から受け取った**アクセスキー**を入力します

アクセスキーは、発行時の1回しか表示されません（システム側にも残していません）。
紛失された場合は、管理者に**再発行**をご依頼ください。古いキーは使えなくなります。

ログインは**12時間**で切れます。共用の端末では、お帰りの前にログアウトしてください。

> アクセスキーは、社内のチャットやメールに貼らずにお渡しください。
> キーを持っている方は、応募者の回答をすべて読めます。

## 1日の流れ

### ① 候補者を招待する（選考担当・管理者）

1. **候補者管理** を開く
2. 氏名・応募職種を入力（メールアドレスは任意ですが、入れると案内文が作れます）
3. **受付期間**を決める（既定は7日後まで）
4. 「**URLを発行する**」

発行された URL は**その方専用**です。推測できない文字列で、次の性質を持ちます。

- 受付期間を過ぎると開けません
- **一度受験を完了すると、二度と開けません**（再受験はできません）
- 途中で回線が切れた場合は、期間内なら**続きから再開できます**

メールアドレスを入れておくと、URL と期限を差し込んだ**案内文**がその場で作られます。
コピーして、いつもお使いのメールソフトから送ってください。
（システムからの自動送信は行っていません。差出人がご担当者ご本人になるほうが、
応募者にとって自然だからです。）

**送り間違えたときは、その場で無効化してください。** 一覧の「**無効にする**」を押すと、
以後そのURLは開けなくなります。取り消しは効きますので、迷わず押してください。

### ② 受験状況を見る

| 表示 | 状態 |
|---|---|
| 未受験 | URLを発行済み。まだ開かれていません |
| 受験中 | 開始されましたが、まだ回答が届いていません |
| 受験済み | 回答が届いています。**選考状況**に出ます |
| 期限切れ | 受付期間を過ぎました |
| 無効 | ご担当者が無効化しました |

期限切れの方に再度受けていただきたい場合は、「**期限を延長**」してください。
新しくURLを発行し直す必要はありません。

### ③ 回答を読み、合否を決める（選考担当・管理者）

**選考状況**を開き、左の一覧からお名前を選びます。

画面に出るもの:

- **AIの参考スコア（20点満点）** と4つの評価軸ごとの点数
- **AIの所見**（なぜその点数か）
- **設問と回答の全文**、設問ごとの回答時間

**AIのスコアは参考です。合否はご担当者が決めます。**
このシステムは、AIの点数だけで自動的に落とすことを一切していません。
点数が低くても、回答を読むと評価すべき方がいらっしゃいます。
**必ず回答本文をお読みください。**

決まったら「**✓ 合格**」「**— 保留**」「**× 不合格**」のいずれかを押します。
同じボタンをもう一度押すと未判定に戻ります（押し間違いは取り消せます）。

**メモ**は、その判断の理由を残す欄です。
あとで「なぜこの方を不合格にしたのか」と問われたとき、
記録で答えられるのはこの欄だけです。ひとことで構いませんので、残してください。

誰がいつ合否を押したかは、自動的に記録されます（**担当者管理**の操作ログ）。

## 月に一度、していただきたいこと

### 振り返りを見る（**運用の振り返り**）

#### 「AIは低評価、人事はご合格」の人数

AIの点数だけで足切りしていたら、失っていたはずの方の人数です。
**この数字が0でないことが、人が確認する運用に意味がある証拠**になります。

#### 評価軸ごとの判別力

合格された方と不合格の方で、その軸の点数に差が出ているかを見ます。

| 表示 | 意味 | どうするか |
|---|---|---|
| 効いています | その軸は判断に寄与しています | そのままで結構です |
| やや弱い | 差が小さめです | 様子を見てください |
| **効いていません** | 合格・不合格で点差がありません | **観点の書き直し**をご検討ください |

「効いていません」は、その軸で採点しても合否の役に立っていない状態です。
**コンテンツ編集 → 会社情報・動画・評価軸** で、その軸の「評価の観点」を
具体的に書き直してください。書いた文章が、そのままAIへの採点の指示になります。

> 例）「意欲があるか」→「当社の事業内容や職務内容に具体的に触れているか。
> 一般論ではなく、その方自身の経験と結びつけて語れているか」

**判断済みが10件に満たないうちは、画面に警告が出ます。**
数件の平均をもとに設定を変えても、改善ではなく偶然を追いかけることになります。
警告が出ているあいだは、数字を眺めるだけにしてください。

#### 答えられなかった質問

会社説明会のチャットが「採用担当へお繋ぎします」と返した質問が、
よく聞かれた順に並びます。**求職者が実際に知りたがっていることの一覧**です。

「**ナレッジに追加**」を押すと、その質問を持ったままコンテンツ編集に移ります。
回答を書いて保存すれば、次から自動で答えられるようになります。

答える必要のない質問（同じ内容の重複、意味を成さない入力など）は
「**対象外**」で一覧から消せます。

> この記録には、どなたのご質問かは一切残していません（IPも識別子も持ちません）。
> 本文のみを200文字まで、面接記録と同じ期間で自動削除します。

## 内容を書き換える（管理者のみ）

**コンテンツ編集**を開きます。開発会社へのご依頼は不要です。

### チャットが答える内容（ナレッジ）

**チャットは、ここに書かれていることだけを根拠に答えます。**
書かれていないことを尋ねられたら、推測で答えず「採用担当へお繋ぎします」と返します。
事実でないことを応募者にお伝えしないための作りです。

1項目につき、次を入力します。

| 欄 | 書き方 |
|---|---|
| 分類 | 「待遇」「働き方」など。回答の出典として表示されます |
| 代表的な質問 | 「福利厚生を教えてください」など |
| **検索語** | **応募者が使いそうな言い回しを「、」区切りで並べます** |
| 回答 | 実際に表示される文章 |
| 公開 | 外すと下書きになり、チャットは使いません |

**検索語がこの機能の要です。** 一つの事柄でも、応募者の言い方はばらつきます。
「残業」だけでなく「残業時間、忙しい、繁忙期、遅くまで」まで入れておくと当たります。
制度の呼び名（正式名称）だけでなく、**日常の言い方**を入れてください。

### 面接の設問

並べた順に応募者へ表示されます。設問ごとに、どの評価軸で採点するかを選びます。
**最後に、直前の回答をふまえた深掘りの質問が1問だけ自動で追加されます**
（この一覧には出ません）。

「使用」のチェックを外すと、消さずに一時的に休止できます。

### 会社情報・動画

社名とひとこと紹介、説明会動画のURL・長さ・チャプターを設定します。
動画URLを空のままにすると、サンプルのプレースホルダー表示のままになります。

チャプターは1行に1つ、**時刻 → Tab → タイトル → Tab → 関連する質問**の順です。

### 保存について

- 保存すると、**次に開かれた画面から**反映されます
- 変更があると画面下に保存バーが出ます。**押さずに閉じると失われます**
- 「サンプルの会社情報が表示されています」の警告が出ているあいだは、
  **架空の会社の情報が応募者に見えています。** 本番のご案内を始める前に、
  必ず実際の内容へ書き換えてください

## 担当者を管理する（管理者のみ）

**担当者管理**を開きます。

### 追加する

氏名・メールアドレス・権限を入力し、「**追加してキーを発行**」。
表示されたアクセスキーを、ご本人へお渡しください。
**この画面を閉じると二度と表示されません。**

### 退職・異動されたとき

「**停止**」を押してください。その場でログインできなくなります。
（ログイン中であっても、次の操作から弾かれます。）

記録は残ります。過去にその方が押した合否の履歴は消えません。

### 操作ログ

いつ・どなたが・誰に対して何をしたかが並びます。
合否の記録、候補者の登録・無効化、データの削除がすべて残ります。

**ご自身を降格・停止することはできません**（管理者が誰もいない状態を防ぐため）。

## 応募者から「データを消してほしい」と言われたら

1. 応募者は `/privacy` のフォームからご請求になります（またはお電話・メールで）
2. **選考状況**の画面上部に「**未対応の削除請求 ○件**」と出ます。
   「内容を見る」でお名前・ご連絡先・ご依頼内容をご確認ください
3. **ご本人であることを確認**してください（応募時の連絡先との照合など）。
   ご請求は**届くだけで、自動では消えません**
4. 左の一覧からその方を開き、「**この記録を完全に削除**」（管理者のみ）。
   確認が2回出ます。**取り消せません**
5. 削除がお済みになってから、請求の「**対応しました**」を押します

**順序が逆にならないようご注意ください。** 「対応しました」を押した時点で、
請求に含まれるお名前・ご連絡先は消去されます（削除の証跡が、
新たな個人情報の保管先にならないようにするためです）。
先に押してしまうと、どなたのご請求だったか分からなくなります。

削除の対象にあたらないご請求（別件のお問い合わせなど）は「**対象外にする**」で閉じます。
どちらの場合も、理由の記入欄が出ます。記録に残りますので、ひとことお書きください。

削除は、見えなくするのではなく**記録そのものを消します**。
回答・スコア・所見がすべて失われます。

**対応が終わったことは、応募者へご自身でご連絡ください。**
システムからの自動通知は行っていません。

保存期間を過ぎた記録は、**毎日自動で削除**されます（既定：面接記録180日、
候補者365日、操作ログ730日）。日数の変更は開発側の設定作業になります。

## 応募者への案内で、お使いいただける文面

> ■ 会社説明会（24時間ご覧いただけます）
> https://（貴社のURL）/briefing
> 動画のご視聴中でも、ご質問はチャットにお気軽にどうぞ。
>
> ■ オンライン面接
> （候補者管理で発行された、その方専用のURL）
> ○月○日までにご回答ください。所要時間は15分ほどです。
> ご回答は採用担当者が拝見し、**合否は担当者が判断いたします。**
> 個人情報の取り扱い： https://（貴社のURL）/privacy

**「合否は担当者が判断いたします」の一文は残してください。**
AIが自動で合否を決めていると受け取られると、応募者の心証を損ないます。
実際にそうしていない以上、明記しておくほうが誠実です。

## 困ったとき

| 症状 | 考えられること |
|---|---|
| 応募者が「URLが開けない」 | 期限切れ・受験済み・無効化のいずれか。**候補者管理**で状態をご確認ください |
| 受験済みなのに選考状況に出ない | 回答の送信中に通信が切れた可能性。ご本人の端末には残っています。ご連絡ください |
| チャットが「採用担当へお繋ぎします」ばかり返す | ナレッジの**検索語**が足りていません。**振り返り**で実際の質問をご確認ください |
| ログインできない | キーの再発行を管理者へ。停止されている場合もあります |
| 「この端末のみ」と表示される | データベースに繋がっていません。開発側の設定をご確認ください |
| コンテンツ編集が開けない | 管理者権限が必要です |

**応募者の回答が届かない・消えたようだ、という場合は、その場でご連絡ください。**
選考の公平性に関わるため、こちらで記録を確認します。

## このシステムがしないこと

導入のご説明で誤解が生じないよう、明記しておきます。

- **AIが合否を決めることはありません。** AIは回答の整理と参考スコアの作成までです
- **チャットは、登録されていないことを推測で答えません。** 分からないことは分からないと返します
- **面接の映像・音声は扱いません。** 文章でのご回答のみです
- **応募者に自動でメールは送りません。** 案内文を作るところまでです
- **合否の自動通知はしません。** 通知はこれまで通りの方法でお願いします
