# faq-ai — AI採用デモ（会社説明会チャット ＋ AI面接官）

採用案件の提案用デモ。**受注を取るためのデモであり、本番システムではない。**

## 何を作るか

| # | 機能 | 内容 |
|---|---|---|
| ① | AI人事担当者による会社説明会 | 会社説明の動画を24時間視聴でき、その場でチャットAIが質疑応答する専用ページ |
| ② | AI面接官 | 求職者へ送る個別URL上で、AIが質問→回答を分析→スコア化するオンライン面接 |
| ③ | 人事ダッシュボード | 回答ログを見返し、**人が最終合否を決める**画面（提案書での約束を証明する部分） |

### 動かし方

ビルド不要。`index.html` をブラウザで開くだけで動く（`file://` でも可）。
GitHub Pages に置けば、そのまま公開URLになる。

> **動画はプレースホルダー**です。`briefing.html` の `.player__stage` と
> `assets/js/briefing.js` の `Player` を `<video>` に差し替える前提で作ってあり、
> チャプターの時刻はそのまま `video.currentTime` に対応する。

## 技術構成

ビルド不要の静的サイト（HTML / CSS / 素のJavaScript）。GitHub Pages で公開する。
npm も Node も不要 — リポジトリを clone してブラウザで `index.html` を開けば動く。

### デモモード / ライブモード

- **デモモード（既定）** — APIキー不要。定義済みナレッジから応答する。商談中に通信やAPIの都合で止まらないための保険。
- **ライブモード** — 画面上でAPIキーを入力すると、実際に Claude API を呼んで応答する。「本物のAIである」ことを見せる用。

> ⚠️ ライブモードがブラウザからAPIキーを使うのは**デモ限定の割り切り**。
> 本番ではキーはサーバ側に置き、ブラウザには一切出さない。

## 本番との差分（デモでは省略している点）

| 項目 | デモ | 本番 |
|---|---|---|
| データ保存 | ブラウザの localStorage | サーバのデータベース |
| APIキー | ブラウザで入力 | サーバ側で保持 |
| 個別URL | 擬似トークン（`?token=`） | 認証付き・期限付き・使い切りURL |
| 動画配信 | サンプル動画を埋め込み | 動画配信サービス経由 |
| 応募者データ | 架空のダミーのみ | 個人情報保護方針に沿った保存・削除 |

## データの取り扱い

このリポジトリに登場する会社名・候補者名・回答内容は**すべて架空**。
実在の企業・個人の情報、およびAPIキーはコミットしない。
