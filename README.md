## 何を作るか

| # | 機能 | 内容 |
|---|---|---|
| ① | AI人事担当者による会社説明会 | 会社説明の動画を24時間視聴でき、その場でチャットAIが質疑応答する専用ページ |

## 技術構成

**ビルド不要の静的サイト ＋ Vercel サーバーレス関数**の2層。

| 層 | 中身 | 役割 |
|---|---|---|
| ブラウザ | `*.html` / `assets/` | 画面。素のHTML・CSS・JavaScript（フレームワーク無し） |
| サーバー | `api/*.js` | Claude の呼び出し。**APIキーはここだけが持つ** |

ナレッジ（`assets/js/knowledge.js`）と面接設問（`assets/js/interview-data.js`）は、
ブラウザとサーバーの**両方が同じファイルを読む**。末尾の `module.exports` の分岐は
ブラウザでは実行されない。定義が2箇所に分かれて片方だけ古くなる事故を防ぐため。

デプロイ手順は [docs/05-deploy.md](docs/05-deploy.md)。

### デモモード / ライブモード

- **デモモード（既定）** — 外部通信なし。定義済みナレッジから応答する。
  商談中に通信やAPIの都合で止まらないための保険。`index.html` を直接開いても動く。
- **ライブモード** — サーバー（`/api/*`）経由で Claude を呼ぶ。
  デプロイ済みかつ `ANTHROPIC_API_KEY` が設定されている場合のみ選択できる。
  使えない環境では、その理由とともに自動的に選択不可になる。

> APIキーはサーバーの環境変数にのみ置く。ブラウザからは見えず、画面で入力もしない。

## 本番との差分（デモでは省略している点）

| 項目 | デモ | 本番 |
|---|---|---|
| APIキー | **サーバー側の環境変数（本番と同じ構成）** | 同左 |
| データ保存 | ブラウザの localStorage | サーバのデータベース |
| 個別URL | 擬似トークン（`?token=`） | 認証付き・期限付き・使い切りURL |
| 動画配信 | プレースホルダー | 動画配信サービス経由 |
| 応募者データ | 架空のダミーのみ | 個人情報保護方針に沿った保存・削除 |
| 管理画面 | 誰でも開ける | ログイン認証と操作ログ |

### 本番移行時にやること（見積もりの対象）

1. ~~サーバー側のAPI窓口を作る~~ … **完了**（`api/` に実装済み。キーはブラウザに出ない）
2. **データベース** — 面接記録を localStorage から移す。保存期間と削除の運用も決める
3. **個別URLの発行** — 認証・期限・使い切りの仕組み。メール送信と合わせて
4. **管理画面のログイン** — 人事担当者の認証と操作ログ
5. **ナレッジの更新手段** — 人事の方がご自身で書き換えられる画面
6. **動画配信** — 配信サービスの選定と埋め込み
7. **個人情報保護方針への反映** — 応募者への説明文と同意取得の文面

## データの取り扱い

このリポジトリに登場する会社名・候補者名・回答内容は**すべて架空**。
実在の企業・個人の情報、およびAPIキーはコミットしない。

点検済み（Phase 4-5）:

- コミットされたAPIキー … なし
- メールアドレス … `recruit@example.invalid` のみ（`.invalid` は予約TLDで実在しない）
- 外部通信先 … `api.anthropic.com` のみ。CDN・外部フォント・解析タグの類は一切なし
  → **デモモードは通信が無くても完全に動作する**（商談会場のWi-Fiに依存しない）
- 電話番号・住所などの実在情報 … なし

## デモの見せ方（要点）

人事ダッシュボードで **鈴木 健（9点）** を開くと、AIのスコアは低いが
回答を読むと独学でExcelマクロを作り業務を月6日分短縮している、という記録が出てくる。
ここで人事が「合格」を押せる——これが提案書でお伝えした
「AIだけで落とさない」を画面で示す場面。

## 動作確認（_selftest.html）

`_selftest.html` をブラウザで開くと、4画面を iframe で読み込んで実際に操作し、
53項目を自動で確認する。結果はページ上とタブのタイトルに出る。

確認していること（抜粋）:

- チャットが**答えるべき質問に正しく答える**（6パターン）
- チャットが**答えるべきでない質問を人事へ引き継ぐ**（4パターン）
- AI面接を6問すべて通し、記録が保存され、**完了画面に合否が出ない**こと
- ダッシュボードで**人が合否を押せる**こと、一覧のバッジが連動すること

サーバー側（`api/*.js`）の構文確認も含む（この環境には Node が無いため、
`new Function` で解析のみ行っている）。

ナレッジや質問を差し替えたら、このページを開いて全項目がOKになるか確認する。
